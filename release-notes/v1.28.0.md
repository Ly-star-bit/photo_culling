这一版专门改相册：自动编排出来的初稿改起来更快（整本概览、跨页之间直接挪照片、镜像、左右页分开换版式、锁住跨页、换照片推荐），交给印厂和客户那一段补齐了（印厂规格、导出前检查、只导某几个跨页、看版 PDF、封面）。另外修了相册里七个小问题和暗房里的一处。

## 新：整本概览

- 跨页条左边多了「整本」按钮（快捷键 G）：画布区摊开整本，封面排第一张，每张标跨页号、张数、锁。滑杆调缩略图大小。
- 单击选中，⌘ 点加减，⇧ 点连选，⌘A 全选。
- 拖动排序，插入的地方画一条竖线；多选了拖其中一张就整批一起挪。
- 右键（或选中后上面那一条按钮）锁住 / 解锁 / 镜像 / 删除；⌫ 删选中的。
- 从托盘把照片拖到某个跨页上就加进那一页。
- 双击回到编辑那一页；Esc、G 或再点「整本」也回去。

## 新：跨页之间随便挪

- ⌘← / ⌘→ 换跨页（和暗房一样）。在输入框里打字时还是挪光标。
- 跨页条的卡片能拖动排序；托盘里的照片、画布上的格子都能拖到跨页条的卡片上，直接放进那个跨页：照片当场落下，两边自动重排（后台再细排一遍，不多占一步撤销），⌘Z 一步撤回。
- 右键画布上的照片格（或 ⌃ 点）「移到第…个跨页」：跨页多时按 10 个一组，也可以填号。以前只能挪到相邻的跨页。
- 同一张照片不能上两个跨页：放不进去时状态栏说它在第几个跨页上。

## 新：「这个跨页」

- 不选格子时右栏「这个跨页」多了：
  - 「左页 ‹ ›」「右页 ‹ ›」：只换一边的切法，另一边和中缝不动。点一下画布后也能按 Q / A（左页）、W / S（右页）。
  - 「镜像」：左右对调，照片本身不翻。
  - 「锁住这个跨页」：「自动编排」「整本婚礼相册」原样留着锁住的跨页，照片一张不丢。锁住的第一个跨页当扉页用，再编排不会多出一个扉页。

## 新：换一张

- 选中一张照片，「格式」里多了一节「换一张」：一排候选，标着理由（同连拍 / 同场 / 相似）。在别的跨页上的标「第 N 跨页」，客户选中的标紫心，废片压暗。
- 点一下就换。候选在别的跨页上时两格对调。
- 没上过版的排在前面，同连拍 > 同场 > 相似，同类按分数。

## 新：印厂规格

- 「文档 › 画布」相册的尺寸菜单换成印厂规格：方册 30×30 / 25×25 / 20×20 / 15×15、横版 30×20 / 40×30、竖版 20×30，各有平铺、胶装两种。前四个和以前的相册画布一模一样。
- 规格里能改：页数上下限、每次加几 P、首尾是不是单页、中缝留多宽、色彩（sRGB / Adobe RGB）、JPEG 质量。自定义尺寸填单页的厘米数。
- 改好的可以「存成规格…」，下次直接选。
- 默认值都是保守的（20–60P、每次加 2P、出血 3mm、安全区 5mm），界面上写着「照印厂给的改」。
- 跨页条上的跨页数不合印厂的页数规则时标橙，悬停说清楚多了 / 少了几 P、再加 / 减几个跨页（到多少 P）；规则本身凑不出来时也直说。
- 选 Adobe RGB 时，导出的 JPEG / PNG / TIFF 和印刷 PDF 都转成 Adobe RGB 并嵌配置文件。选 sRGB 时和以前一个字节都不差。导出的 JPEG 都是基线（baseline）格式。

## 新：导出前检查

- 「导出 ▾」里多了一节「导出前检查」，一条一行，点一下跳到那个跨页、选中那一格。
- 会拦下来（导出前先问一次）：空照片格、放大超过 150%、页数不合印厂规则、同一张照片用了两次、胶装时脸压在中缝上。封面上的空照片格、放大过头也算（只导几个跨页时不查封面）。
- 只提醒：放大 120–150%、平铺时脸压中缝、字出了安全区或压进中缝、贴边的照片没铺到出血、首尾单页那半边有东西、正文还是灰条，以及封面的书脊太窄、脸贴着书脊。

## 新：只导某几个跨页、看版 PDF

- 「导出 ▾」里可以选范围：全部 / 当前跨页 / 自定义（比如「1-3, 7」）。文件名还是原来的跨页号。只导一部分时不出整本的印刷 PDF，免得缺页的 PDF 被当成整本发给印厂。
- 「导出 ▾ › 印刷 › 出看版 PDF」：给客户看的低清合并 PDF，第一页是封面，之后每个跨页一页，页脚印「跨页 7 / 20 · 标题」和这一页的照片文件名。客户回「第 7 页把 DSCF7212 换掉」能直接对上。

## 新：封面

- 跨页条最前面一张「封面」卡（不算在跨页数里）。没做封面时是「+ 封面」，点了做一张并进入编辑封面。
- 编辑封面时画布是整张封面，封面那一块和跨页一样点格子选中、从托盘拖照片进来换、双击改字；点任何跨页卡回去。暗房、散落、印样、贴纸这些不适用的按钮会灰掉。
- 「文档 › 封面」：一键「做封面」，用扉页那张照片、标题和日期（没有扉页就挑分数最高、有人脸的一张）。封底 | 书脊 | 封面排在一整张上，四周带包边和出血。
- 书脊宽填印厂给的数；空着时按页数和纸厚估，旁边写着怎么估的。书脊上的标题、日期竖排（中文立着排，英文、数字转 90° 从上往下读）。
- 封底可以放一张小照片加一行字。
- 导出时封面单独出「名_封面.jpg」和「名_封面.pdf」，不混进跨页 PDF。PDF 的裁切线在包边外沿（包边要折到板子背面），板边和书脊另画虚线折线。
- 「自动编排」只重排跨页，做好的封面不动。编辑封面时点「自动编排」、换装订、套规格，会先回到跨页。
- 估书脊用的纸厚跟着装订走（手改过的不动）。「清空托盘」连封面一起去掉，⌘Z 能撤回。

## 新：AI（MCP）能改整本了

- 以前 AI 只能动当前跨页。新加 6 个工具（第 25–30 个，原来的编号不变）：
  - `collage_pages`：翻页、加 / 删 / 挪跨页、锁住 / 解锁、镜像、左右页换切法；
  - `collage_move_photos`：照片挪到某个跨页，或从托盘放进去；
  - `collage_replace_photo`：换一张（在别的跨页上就对调）；
  - `collage_preflight`：导出前检查，「拦」和「提醒」分开；
  - `collage_print_spec`：读 / 套印厂规格、改页数和色彩这些规则；
  - `collage_cover`：做封面、改书脊和封底、去掉封面。
- `collage_export` 加了 `pages`（只导某几个跨页）和 `proof`（看版 PDF），每次导出都带上导出前检查的结果。
- `collage_get_state` 多了整本的概况（每个跨页的照片、锁、页数合不合规、封面）和换照片的候选。
- 每个改动都是一步撤销，`app_undo` 能撤回。

## 修复：相册里七个小问题

- 平铺对裱下「+」加的空跨页放一张竖图，以前被裁成 2:1 的横条、脸压在中缝上；现在竖图放一页完整显示，够宽、中缝没脸的横图才铺满跨页。
- 胶装下只有一张照片的跨页，另一页以前留着空照片格（导出时弹「空照片格」）；现在是留白。
- 批量页「拼图 (N)」在相册里以前把所有没上过版的照片塞进一个跨页（40 张就 40 格）；现在按拍摄时间分成几个跨页。
- 同一个跨页里左页放早拍的、右页放晚拍的。以前左右是随机的。
- 同一张照片不能上两个跨页了（以前拖托盘能再放一次，不提示）；要挪就右键「移到第…个跨页」。
- 「自动编排」以前直接整本替换，不确认。
- 相似去重以前只比分数前 120 张，300 张的婚礼后面那些不参与；现在比前 500 张。

## 修复：暗房

- 撤销、AI 加 / 删跨页换了页以后，样张的焦点以前还停在上一页套的那款，按 ⏎ 会把它套到这一页；现在跟着页走。
