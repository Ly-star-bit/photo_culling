这一版专门改拼图页用起来的手感：画布大了、能放大看了，右键有菜单了，几处要找半天或者看不清的地方顺了一遍。排版、导出出来的图一个像素没变。

## 新：画布大起来

- 两边的栏不再各撑到最宽：默认左 250 / 右 330（以前 1440 宽的窗口里是 340 + 380，相册跨页只画 660×330），拖两栏的边改宽度，双击回默认，下次打开还是你拖的宽度。
- 两栏都能收起：左栏 ⌃⌘S、右栏 ⌥⌘S（和批量页的筛选面板一样），或者点页签那一行最边上的按钮；收起以后画布角上有一个按钮摊开。「带我去」、指路的字要去的那一栏收着时会自己摊开。
- 没有备选时备选条收成一行（以前照样占一整条，相册里大多数时候是空的）；整本概览开着时不再摆跨页条（概览里就是这几个跨页）。
- 1440×900 的窗口里相册跨页从 660×330 变成 790×395；两栏都收起是 1240×620。

## 新：画布能放大

- 捏合、⌘ 滚轮在指针那一点放大 / 缩小；放大以后滚动就是平移。
- ⌘= 放大、⌘- 缩小、⌘0 适应窗口、⌘1 实际像素（再按一次回到适应）。画布右下角有一个小条：− 百分比 +，百分比是实际像素的比例。
- 放大以后预览按放大的倍数重渲（最多 1600 万像素），不是把小图拉大：30×30 的相册可以放进去看脸、看小字、看中缝。
- 放大着照样能选格子、拖缝、拖照片、调裁切（调裁切时捏合还是缩放照片）。换画布、进出封面编辑回到适应。

## 新：画布右键

以前单张拼图里右键什么都没有，相册里只有「移到第…个跨页」。现在右键先选中点到的那一样，再给它最常用的几样：

- 照片格：调整裁切、景别（自动 / 全身 / 半身 / 特写 / 封面）、完整显示、还原自动取景、换一张、在照片上加字、在暗房里调这一格、锁定、这张不加水印、移到第…个跨页、删除格子。
- 文字格：改字、锁定、删除。贴纸、手写字、相纸：改字、复制一份、移到最上面 / 最下面、摆正、删除。
- 一条缝：横竖翻转。空白处：换一批、贴合原比例、参考线、放大 / 缩小 / 适应 / 实际像素。

## 顺手的

- 「样式 › 风格」默认只摆两排（正在用的那个一直看得见），点「全部 N 个风格」摊开：色调、留白、底色、边框不用再滚过二十来个预设才看得到。
- 面板里的说明字从 10pt 三级灰改成 11pt 二级灰：深色底上以前几乎读不出来。
- 空画布中间直接有按钮：托盘空着是「带精选进来（N 张）」「精选 + 可用」「添加文件…」，托盘有照片是「自动排版」/「自动编排」。
- 「素材 › 贴纸与手写」每个贴纸一张小图，加之前看得到样子。
- 拖格子时有一张半透明的小图跟着指针。
- 鼠标停在备选条的一张上，画布底下浮一张大的。
- 托盘底下多了缩略图大小的滑杆和「按章节」分组（一章一段，段头可以「全选」这一章）。
- 点过托盘以后 ← → 照样换备选（以前要先点一下画布）。
- 「文档 › 标题和刊头」的输入框占位字不再露出 {subtitle}、{issue}。
- 快捷键一览（?）补上了上面这些。

## 怎么验的

- 拼图门禁（照片出图逐像素比）和上一版一样；自检 23 条全过，新加一组「拼图工作区」（两栏怎么让宽、缩放怎么夹、指针处放大、风格两排、托盘分组、九个贴纸小图渲得出来）。
- 界面用离屏快照核对（两栏宽度、收起、放大、右键菜单的内容、悬停大图、贴纸小图、空画布）。
- 拖分隔条、捏合、滚轮、右键弹出、悬停这几样离屏收不到鼠标事件，没法自动验，要在真 app 里点一遍。
