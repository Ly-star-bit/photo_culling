## 新增：拼图的「方案」栏

以前拼图一次只有一版：套了别的模板，原来那一版就被盖掉，只能 ⌘Z 找回。现在可以把好几版设计存下来并排比着挑。

- 顶栏新增「存成方案」（⇧⌘S）：把现在这一版（画布、样式、文字、所有页、水印）存进拼图页底下的「方案」栏，一排缩略图。
- 点缩略图就切回那一版，算一步撤销，⌘Z 回到切之前。和现在一模一样的那个描蓝边；切过去又改了，名字后面标「改过」。
- 右键：用现在的样子覆盖它、改名、删除。覆盖和删除会先问一句。
- 方案栏不跟着 ⌘Z 走：按 ⌘Z 往回翻设计时，存好的方案不会被撤掉；存方案也不会清掉重做记录。
- 方案跟着这一场存盘，关掉 app 再开还在；一场最多 30 个。切到某个方案时托盘不变，它用到而托盘里已经拿掉的照片会补回去。

## 新增：AI 可以一次出好几版设计（MCP）

MCP 多了两个工具：`collage_save_variant`（存成方案）和 `collage_open_variant`（切到方案）。可以这样说：「用这一场出 3 个不同风格的拼图，报纸风、九宫格、留白杂志各一版」——AI 每排好一版就存成一个方案，排完三个缩略图并排放在方案栏里，你点着比，挑中哪个导出哪个。`collage_get_state` 里也能看到存过的方案。

用 Claude Code 的话，想让新的两个工具也不再每次询问，把它们加进设置里的放行清单（README「审批」一节有完整的列表）。

## 新增：AI 可以直接导出拼图（MCP）

新工具 `collage_export`：和拼图页的「导出」按钮一样，写进导出页设的输出目录（没设过就是照片文件夹里的「拼图导出」），同名的自动加 -2、不覆盖。

- 清晰度可以让 AI 选：标准 / 2 倍 / 3 倍（九宫格、轮播最多 2 倍，A4、相册这些印刷画布不放大），格式、文件名也可以只为这一次指定，不改你在导出页上的设置。
- 能直接导某个存着的方案，不用先切过去：「把刚才三个方案都按 3 倍导出来」。
- 不改拼图、不进撤销、不弹访达窗口；app 状态栏会说一句导出了几个文件。
