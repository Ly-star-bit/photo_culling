这一版主要改的是判决本身：判虚焦改看眼睛那一块的「对焦」，闭眼、曝光、人脸质量分也都换了算法。另外是相册印刷、批量页、导出、给 AI 用的工具、主题和安装的一批改进。

## 升级后先做一件事：老场次重新分析一次

分析版本从 2 升到 4。打开以前分析过的拍摄，点「重新分析」，整场重算一次（只这一次）：

- 改判过的、客户选中的都保留。
- 没重新分析之前，判决和升级前一张不差：存过的阈值自动换算到新刻度（原来是哪一档，换过来还是哪一档），检视器里「对焦」前面带「≈」，表示是按老锐度折算的。
- 重新分析后，少数连拍组的精选可能换成同组里几乎一样的另一帧（人脸质量分现在每次都一样了，见下面），不会有照片因此变成废片。

## 判决

### 判虚焦看「对焦」

- 以前判虚焦看「锐度」，它跟着照片明暗、景别、照片大小一起变：暗一两档、逆光、特写的清楚照片会被冤成虚焦；焦点落在嘴上、眼睛发虚的，又会因为嘴清楚被放过。
- 现在看新的「对焦」数：只量眼眉那一块对没对上焦，不受明暗、景别、照片大小影响。清楚的照片大约 80–110。
- 右栏第一根滑杆改名「对焦下限」，三档按「多糊才判」重定：**宽松 45**（明显跑焦才判）、**标准 60**（放大到 100% 看得出发软就判）、**严格 70**（轻微发软也判）。鼠标停在预设按钮上有一句说明。
- 「锐度」照旧显示，只管排先后、管连拍里比谁更清楚。

合成测试：同一位模特 8 张原片，各做 49 种退化，共 392 张，三档各判一遍。下表是判成虚焦的张数（宽松 / 标准 / 严格）：

| | v1.32.0 | v1.33.0 |
|---|---|---|
| 应该判废的 136 张（明显跑焦、运动模糊、只糊了眼睛） | 0 / 26 / 83 | 80 / 105 / 122 |
| 应该留的 152 张（原片、轻微柔化、暗 1–2 档、小图、噪点、特写） | 0 / 8 / 33 | 0 / 0 / 0 |
| 看用途的 104 张（轻微发软，糊不糊看要拿去干什么） | 0 / 0 / 3 | 15 / 39 / 73 |

### 其它判决改动

- **人脸质量分每次一样了**：同一批照片不管分析几次、在哪台电脑上分析，人脸质量分、精选和去重结果都一样。连拍里两帧几乎一样时，不再像抛硬币。
- **闭眼**：眼睛按两眼连线转平了再量。歪着头、相机没端平、方向标记写错时，闭眼也认得出；模特垂眼往下看的那张，不会因为和看镜头的那张连拍在一起就被当成闭眼。
- **曝光裁切只数人**：影棚白底、黑底、高调、低调、逆光背景打爆的人像，人本身曝光正常时不再被判「曝光裁切」。脸打爆、欠曝、剪影照样判废。分析因此慢约 4%。
- **近似重复里糊的那张**：一组近似重复里，比最清楚那张明显糊一截（锐度低 8% 以上）的不拿精选；开「近似重复只留最佳」时，留下的是清楚的那张。AI 表情分仍然最优先。
- **排先后用同一把尺子**：「场内按评分」、连拍挑选的顺序、「这组全留」、精华 Top N、时间轴悬停卡片的代表照片、AI 助手看到的近似重复名次，现在都和精选星、#1 #2 #3 一致：明显更糊的排在清楚的后面，「场内按评分」时废片排最后。
- 连拍挑选里黄色的「眯」按转平后的眼睛读数重新核过，标准不变（比这个人本组睁得最开的那张小四分之一以上）。垂眼、歪头的照片不会被标上。

### 分析结果更经得起意外

- 解不开的照片、取消分析时还没轮到的照片，状态栏会一直显示「N 张没进网格」。鼠标停上去能看到名字，点「重新分析」就能补上。诊断包和 AI 助手也用同一个说法。
- 场次文件里坏了一行，只少那一张，不会整场空白；重新分析只重算坏的那几张。
- 分析后在访达里改名、挪进子文件夹的照片，重新分析时会认回来，改判和客户选中也跟着回来。
- 手改阈值文件写了离谱的数，app 不会一打开就崩，滑杆停在两头。
- 文件名很长（到 255 个字符）的照片也能分析；名字像照片的文件夹（比如「客户挑的.jpg」）不再被当成一张坏照片。
- 「人工改判 N」只数这一场里还在的照片。

## 批量页、看单张、审片、连拍挑选

- **右键**：网格里的照片能右键了：改判、看单张、从这张开始审片、在访达中显示、用…打开、复制文件名、放进拼图托盘。选中几张时，对选中的全部生效。
- **拖出去**：照片能直接拖出去。拖到访达是复制原片；拖到 Capture One / Lightroom / Photoshop 的图标上，就用它打开；能一次拖多张。只复制，原片不挪。
- 菜单栏「文件」里加了「打开文件夹…（⌘O）」「开始分析 / 重新分析（⌘R）」「导出 JPG…（⇧⌘E）」。
- 右栏「筛选严格度」拆成「判废线」「分组」「视图与提醒」三张卡，调哪一样会动判决，一眼看得出。
- 看单张按 Z 放大，Esc 先退出放大、再按才关闭。判决按钮上写着 1 2 3 0，按 ? 看快捷键。
- 审片、看单张放大以后翻页，会保持放大并落在脸上，下一张原图提前解好。没放大时按 P，先放大再开对焦高亮。
- 审片看竖片时，人脸特写放在照片右边的黑边里（最大 260pt），不放大也看得出眼睛实不实。
- 竖拍按 Z 放大，每张少等约 0.2 秒，和横拍一样快；合影小脸的闭眼检查在竖拍上快约三成。画面和判决都没变。
- 按分组时点小组头的「✓」，网格底下会提示这一场留了哪张、废了几张，⌘Z 能撤销。
- 改判时照片直接跳到新位置，不再有整格挪位的动画。系统开了「减少动态效果」时，各处动画都直接到位。
- VoiceOver 能念出右栏、状态栏滑杆的名字（比如「对焦下限，60」）。网格里每张照片念成一句：文件名、判决、本场第几名。
- 连拍挑选里横竖混拍时，竖片、横片各按自己的方向占满。窄窗口里，顶栏按钮只留图标，不截字。
- 机身时间被复位过的照片混在一场里时，时间轴、悬停卡片和「只看这一章」会带上年份。
- **更快**：
  - 一个场连拍几百上千张时，「按分组」不再一次铺开整场。方向键和改判快 4–12 倍：300 张的场，按一下方向键从约 42 毫秒降到约 13 毫秒。
  - 一场 3000 张，算一遍判决从约 48G 条指令降到约 5G。
  - 几千张的拍摄拖「对焦下限」「曝光裁切上限」「人脸质量」滑杆，每拖一格只重判越过线的那几张，以及它们牵到的组、场、章节。
  - 打开场次后第一次按方向键，不再卡一下。
- 用命令行或自动化跑批量页（快照、测速）时，不会再改掉 app 记住的网格模式、缩略图大小。

## 导出和交付

- 导出 JPG 新增「范围」：精选、精选 + 可用之外，还能只导选中的、客户选中的，或者当前筛选下的（比如只看这一章）。
- 导出设置能存成预设（比如「原尺寸」「小红书」「朋友圈」）。勾上几套点一次，全部导出，每套放进一个以预设名命名的文件夹。
- 水印页的预设连导出设置（尺寸、锐化、质量、文件名）一起存。「批量导出」灰着时，状态栏直接写出还差哪几样。
- 选片确认表每张照片下面多了「放大」：先看到从原片裁的脸部特写，再往下是整张，能左右滑，也能直接在里面选这张。客户在手机上也看得清脸。
- 导出 JPG、精华 Top N 做完，会在访达里选中导出的文件夹。
- 原尺寸导出 JPG、水印批量导出快约 3 倍（16 核的机器；内存小的机器会少开几路）。竖拍整幅解码省一半 CPU，长边 4096 的交付快一倍。导出的图和以前一个字节都不差。
- 修了水印批量导出时，偶尔头几张的 EXIF 字号比后面大的问题。
- 失败名单统一写成「A、B、C 等 N 张」；导出 JPG 的完整失败名单记在交付记录里。
- 导入客户选择时，文件名首尾带空格、句点的也认得出；认不出的行列在「没认出」里。

## 拼图和相册

- **印刷出血补足 3mm**：以前其实只有 2.96mm（300dpi 下 35 像素），按「不少于 3mm」审稿的印厂可能报不足。现在是 36 像素。以前做的相册打开时会自动改好，导出的跨页图每边多 1 像素。
- 相册里手动裁满过的照片，在同一跨页挪走别的照片、或者往这个跨页加照片以后，裁切不会再被改回留白。真带不过去时，状态栏会点名是哪几张。
- 整本导出时按内存同时渲 2–3 个跨页，10 个跨页从约 6 秒降到约 4 秒。取消时要等正在渲的那两三页写完。
- 存了几个方案以后，拖缝、拖边距更跟手：底下的方案栏和备选条只在真有变化时才刷新。

## 给 AI 助手用的工具（MCP）

- 托盘空着时让 AI 做相册，它知道先把照片带进托盘，不会去改你的判决。照片不够、模板上有空格子时，它会收到提醒。
- AI 能读回客户回复里的修图要求（比如「去路人」），能只列客户选中的照片，或者只列还没定下来的连拍。
- 拼图托盘超过 200 张时能一页页往后翻。可以只读拼图状态里要的那几块。小数不再带一长串 0，同样一页能多看一成多的照片。
- 按废片理由找照片时，理由写错会当场纠正。AI 能事先说出拼图会导出到哪、出不出印刷 PDF、带不带水印；加删跨页后书脊宽对不上，它看得出来。
- 撤销客户选择、存方案、实时开关关着时的提示都改对了。重排整本婚礼相册以后，它能说清换掉了几个跨页。
- 单张照片的完整信息里多了一个「对焦」数。

## 主题

- **灰卡**：判决的绿 / 蓝 / 红、客户紫、提醒黄、待处理橙单独提亮，小字放在中灰的栏和卡片上都 ≥ 4.5:1（v1.32.0 只有 3.9–4.4:1）。判决色实心底上的字（连拍挑选的「✕ 废」、审片判决条）在灰卡下换成深色字，其余五套照旧是白字。
- **相纸**：
  - 判决色和待处理橙再压深一档。
  - 批量页、审片、看单张、连拍挑选、时间轴、各个弹框里的灰色说明字，换成主题的暖深灰。
  - 眯眼、淘汰理由、直方图、改判提示条、人脸小图上的记号都读得清了。
  - 空画布是一张白纸。
  - 暗房不再强制深色。
- **石墨（默认）也有看得出的变化**：
  - 说明字略亮一点（#9B9B9B → #A3A3A3）。
  - 分隔线变淡。
  - 拼图底部三条和状态栏同色。
  - 空画布只描一圈线。
  - 网格的焦点框挪到照片外面一圈，和选中框靠形状分开。
- 下面这些现在都跟着主题走了：审片的顶栏、判决按钮那一行和胶片条；导卡、导出、导入客户选择、对时、看单张、「这一版新增」这些弹框；快捷键一览。
- 纯黑、灰卡下选中的照片能看到勾了。拼图里所有选中框多了两道细黑边，压在白纸、白衣服上也看得出选的是哪一格。
- 「胡桃」「午夜」「相纸」的暗房里，样张四周改成不带色的中性灰。「午夜」的冰青色挪了 2°，和判决的蓝隔得更开。
- 时间轴悬停卡片里，字和缩略图周围的一圈灰晕没了。

## 安装和系统

- 新增一条命令安装 / 升级：`curl -fsSL https://raw.githubusercontent.com/Ly-star-bit/photo_culling/main/install.sh | bash`。这样装的不用再去「系统设置 › 隐私与安全性」放行。选片工具开着时它会停下来：先退出，或者加 `--force`。
- Release 页多了一个固定名字的 PhotoCulling.dmg，`releases/latest/download/PhotoCulling.dmg` 永远指向最新版。还多了一个 .dSYM.zip 符号文件，以后有崩溃报告能查到出问题的那一行。
- 系统菜单、打开 / 存储面板、系统报错变成了中文。
- app 有自己的图标了。
- 「帮助」菜单加了「反馈问题…」，版本号和系统版本已经填好。「这一版新增」底下多了「更早的版本说明」。「帮助 › 使用说明」打开的是你装的这一版的说明，也补上了这几版的新功能。
- 诊断包里多了界面语言，以及本地模型要的东西装没装。中文系统报错里的文件夹名、盘名也会打码。

## 已知

- 「对焦」的三档只在一台 X-T50、一位模特、合成模糊上定过。换机身后误杀或漏判多的话，用「标注校准」标几张，准确率报告会写出抓到、漏掉、误杀各几张。高感、噪点很重的照片拍糊了可能抓不到。
- 连拍挑选的「眯」只在一组垂眼连拍上核过，手上没有真眯眼的片。它只是提示，不影响判决。
- 「相纸」下，连拍挑选高亮那一格里的二级字是 4.0:1，还没到 4.5:1。拼图页里还有十来处系统灰没换成主题色。
- 离屏测试里，连拍挑选按 Z 放大偶尔有一格对到背景上；真窗口里会不会这样还没确认。
- 弹出菜单、sheet、拖动、读屏、真机上的动画都没法离屏验，清单在 `culling-poc/LabelGUI/Docs/真机手点清单.md`。
