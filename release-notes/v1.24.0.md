这一版给拼图加了**光谱胶片**：10 个按真实胶片和相纸的光谱数据算出来的色调，配上照着胶片物理做的颗粒和晕光；还有一个新的**暗房**工作台，用你自己的照片挑色调、比原图、看 1:1 的颗粒。项目从这一版起按 GPL-3.0 开源，照旧免费。

## 新增：10 个光谱胶片色调

- 拼图检视器「色调」里多了 10 款：负片「柔肤、暖肤、浓郁、暖阳、清新、淡雅」，反转片「浓艳、清亮、怀旧」，电影负片「银幕」。颜色和影调来自开源项目 spektrafilm（Andrea Volpato）按胶片、相纸光谱数据算出的结果，离线烘成色调表随 app 带着。
- 用法和原来的色调一样：强度、整组 / 这一页 / 这一格三级、统一色温、压字自动判深浅、AI（MCP）设色调、AI 设计版式都直接能用。
- 相机出的 JPEG 本身已经带了影调，烘表时先收了暗部、推了高光，套上去暗部不会压死，白也不会发灰。

## 新增：颗粒和晕光

- 选了光谱色调后，「强度」下面多了「颗粒」「晕光」两根滑杆，只对光谱色调起作用，对整组生效。
- 颗粒照 spektrafilm 的模型加在胶片密度上：50% 大约是这款胶片在 35mm 底片上的真实颗粒，100% 是两倍。每张照片都当成一格 35mm 底片来算；同一张照片每次导出的颗粒都一样。
- 晕光是亮处边缘泛出的一圈暖红光，100% 相当于没有防光晕层的底片。
- 两项都是 0 时，成品和以前一模一样。
- AI（MCP）的 `collage_set_style` 可以设 `film_grain` / `film_halation`，`collage_get_state` 读得回来，一步 ⌘Z 撤回。

## 新增：暗房

- 检视器「色调」里点「进暗房…」，整页换成暗房工作台（深色），点「完成」或按 Esc 回拼图。
- 左边看片台：每款色调都用你这一页的照片印成样张。负片是 135 底片条，反转片装在片框里，电影负片带声带；12 个普通滤镜是白边相纸小样，一眼分得出哪些有颗粒晕光。
- 鼠标停在一款上，中间大预览马上换成它，只是看看、不改拼图；点一下（或按 ⏎）才套用，⌘Z 一步撤回。←→ 换一款，↑↓ 跳两款。
- 大预览里左右拖竖线比原图，按住空格整张看原图。
- 右边：强度试条（同一张照片从 0 到 100% 排成一条，点哪格就设到哪格）、统一色温、颗粒、晕光，和一个按导出尺寸 1:1 的圆形放大镜（点预览换看哪里）。
- 「套用到」可以选整组、这一页（相册）、这一格（点底下这一页的底片条选格子）。颗粒、晕光、统一色温永远对整组。

## 已知问题

- 光谱色调是固定的色调表，不像完整的 spektrafilm 那样逐张自动曝光。偏暗、偏亮的照片，请调低强度，或者先在修图软件里校正曝光。
- 暗房的放大镜按导出尺寸渲染：照片很大时，停手后要等一下才出来，渲染中旧图会压暗。
