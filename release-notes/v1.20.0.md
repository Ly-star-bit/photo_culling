## 新增：让 AI 实时操作选片工具（MCP）

选片工具现在能接 Claude Code、Antigravity 这类 AI 助手。你开着 app，在 AI 那边用一句话说要做什么，app 自己动手，你在窗口里当场看到，⌘Z 照样能撤。

- **看选片结果**：AI 能读 app 当前打开的这一场：精选 / 可用 / 废片各多少张、废片理由、章节、连拍的「场」和近似重复，每张的锐度、人脸和睁闭眼、EXIF。也能看照片：缩小的预览，或者按主脸裁一块放大看眼睛和对焦（和连拍挑选里的放大是同一个算法）。读到的就是窗口里现在的样子，包括还没存盘的改动。
- **替你改判、指给你看**：改成精选 / 可用 / 废片或恢复自动判决（和网格里按 1 / 2 / 3 / 0 一样）；在网格里选中它说的那几张给你看。
- **排拼图**：套模板、一键成套（出一期 / 按卷出印样 / 整本婚礼相册）、换封面、改标题 / 刊头 / 期号和格子里的字、换样式和色调。每一步都带 app 当前画面的预览，AI 看得到排出来的样子。
- **换一场**：在「最近场次」里换一场打开。这会清掉当前这一场的撤销记录，所以 AI 会先问你。
- **每一步都能撤**：AI 的一次操作就是一步撤销，在那一页按 ⌘Z 就行。AI 也能撤它自己刚做的那一步，但你之后又改过的话，它不会去动。

## 怎么打开

1. 照 [README「给 AI 用（MCP）」](https://github.com/Ly-star-bit/photo_culling#给-ai-用mcp)一节配一次：Claude Code 是一行命令，Antigravity 是一段配置。里面还有建议放行哪些操作、哪一个每次都该问你。
2. 自己打开选片工具和要处理的场次，然后在 AI 那边说话就行。
3. 实时操作默认开着。「选片工具」菜单里的「允许 AI 实时操作（MCP）」取消勾选就关掉，AI 的读和改都会被拒绝；再勾上就恢复。

打开之前要知道：AI 看过的预览图、脸部裁块，以及文件名、EXIF、人脸位置、判决这些照片信息，会由你的 AI 客户端发给它背后的模型服务（Anthropic、Google 等），和你在对话里发照片一样。照片不能离开这台 Mac 的话，就别接云端的 AI。

## 窗口里看得到 AI 在做什么

- 窗口标题后面会写「Claude Code 已连接」「AI 正在操作：套模板…」，做完以后 10 秒内写着刚做了什么（「AI：改了标题 · 在拼图页 ⌘Z 撤销」），那一页的状态栏上也是同一句。不用 AI 时什么都不显示，窗口和以前一样。
- 你正在拖动、打字、开着菜单时，AI 的改动最多等 2 秒，你一停手就做；还在忙就先不做，过一会儿再试。开着对话框、在连拍挑选里、在裁切时，AI 会请你先关掉，不会在你眼皮底下换数据。
- AI 的改动不会把 app 拉到前台，也不抢键盘焦点。窗口最小化、在别的桌面上时改动照样生效并存盘，切过去就能看到。

## 它不会做的事

- **不会启动 app**：app 没开时，AI 只能看状态、列出场次和拼图模板，别的都会告诉它「选片工具没开」，请你自己打开。
- **不读你的照片，不直接动你的文件**：AI 那边的程序自己不打开任何照片，AI 看到的图都是 app 出好以后发过去的；它不往选片工具的数据和设置里写任何东西，所有改动都由 app 自己做、照常存盘。它唯一会写的是「图片 › xuanpian-mcp」里给 AI 看过的预览图（7 天以前的、或者超过 1 GB 时自动清理）。
- **不替你打开受系统隐私保护的文件夹**：照片在桌面、文稿、下载、iCloud 云盘、外置盘和存储卡上的场次，AI 不能替你打开，请你自己在侧栏点开；之后看脸只用 app 已经做好的预览，不会因为 AI 弹出系统授权框。
- **app 和 AI 之间不开网络端口**：只用本机、只对你这个用户开放的连接。
- **这一版还不做**：app 没开时读场次、出拼图图片、分析新文件夹。

## 其他改进

- 「文件」菜单里去掉了「新建窗口」（⌘N）：第二个窗口和第一个共用同一套内容，开出来只会互相打架。
- 从 Xcode、IDE 或者脚本里开 app 时，如果看起来像是被 AI 工具启动的（不是从访达、程序坞、启动台打开，也不是在终端里直接运行），app 不弹窗口、直接退出；确实要开窗口时设环境变量 `LABELGUI_ALLOW_GUI=1`。平常打开 app 不受影响。

## 已知问题

- 照片在受保护文件夹里的场次，AI「看脸」只能在 1024 像素的预览上裁，细节有限。
- 在菜单里关掉「允许 AI 实时操作（MCP）」的那一刻已经开始的那一步（比如正在算的一键成套）会照样做完，按 ⌘Z 能撤。
- 图片只在 Claude Code 上实测过。Antigravity 能不能直接看到图片、路径里的中文会不会让它启动失败还没验证；启动失败可以用 README 里的包装脚本。
- AI 那边的程序万一崩了，系统会弹「"选片工具"意外退出」：点「忽略」，别点「重新打开」（那会打开 app），然后在 AI 那边重连。
