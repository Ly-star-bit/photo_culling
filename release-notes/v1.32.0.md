这一版给界面加了主题：六套，随时换。照片、判决、排版、导出出来的图都没变。

## 主题

状态栏右下角多了一个半圆按钮，点开是六张小样，点哪张立刻换（框不关，可以挨个试）。「显示 › 主题」菜单里也有。选的那套记在本机，下次打开还是它。

- **石墨**：原来的那一套，默认。中性的石墨灰，点缀色是暗房安全灯的琥珀。数值一个没动。
- **灰卡**：中灰的壳，点缀色是灰白。界面上除了照片和判决没有别的颜色，看曝光、看肤色最稳（Lightroom、Capture One 那一路）。
- **胡桃**：带一点棕的深灰，黄铜色的点缀。
- **午夜**：带一点蓝的深灰，冰青色的点缀。
- **纯黑**：底是纯黑，栏只比底亮一点，点缀色是白。关了灯在 OLED / XDR 屏上看片用。
- **相纸**：浅色。暖白的壳、白卡片、墨色的字，点缀色是赭石。

定颜色时守的几条：

- 每套只有一个点缀色（选中、现在套着的、这一页的下一步）。判决的绿 / 蓝 / 红、客户的紫、待处理的橙每套都是原来的色相，点缀色只挑它们之间的空位，或者干脆不带色。
- 外壳可以带冷暖，放照片的那一块和暗房里照片四周几乎不带：四周的颜色会带偏人眼对照片冷暖的判断。
- 看大图、审片时照片四周一直是黑的，哪套主题都一样；格子上的黑底角标也不变。
- 「相纸」里判决色和待处理的橙各压深了一档，小字在浅底上才读得清（系统绿在浅底上只有 2.2:1）。

## 顺带

- 以前 app 强制深色。现在窗口的深浅跟着主题走，仍然不跟随系统外观。
- 时间轴的悬停卡片、几处卡片描边原来写死成白色半透明，改成跟着主题。石墨下时间轴悬停卡片的底色比以前深一点点（#2B → #24）。

## 已知

- 「相纸」是这一版新做的，app 以前只有深色。各页的快照都逐张看过，但弹出菜单、sheet、拖动时的样子离屏验不了，清单在 `culling-poc/LabelGUI/Docs/真机手点清单.md` 的「主题」一节。
- 菜单里选中项的高亮仍然是系统的蓝，不跟主题。
- 拼图页的风格、模板、色调和主题无关：那些是成品的样子，主题只是界面。

## 怎么验的

- 新自检 `--theme-selftest`：六套逐套核对字的对比度（正文 ≥ 7:1、二级字 ≥ 4.5:1）、点缀色在各种底上认不认得出、和判决色 / 待处理色的色相隔得够不够远、壳 → 栏 → 卡片是不是一级比一级亮、放照片的底带不带色、石墨的数值没动。
- 开着的时候换主题：离屏先用一套画完再换成另一套，和直接用那一套起的截图逐字节比，批量（按判决 / 按分组）、看单张、连拍挑选、水印、拼图各页都一样。
- 拼图门禁（出图逐像素比）438 张和上一版一样。
