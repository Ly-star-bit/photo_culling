# 真机手点清单

从 v1.20 攒到 v1.30、离屏快照和自检验不了、还没人在真 app 上点过的交互，并成一页。按页签排，一条一句「做什么 → 应该看到什么」。走一遍大约 15 分钟。

**怎么走**：开真的选片工具，打开一场有连拍的拍摄（二十张以上，最好有人像）。对不上的在那一条后面记一句，回头照着修。

**记号**

- 〔假〕这一类事件离屏假鼠标（`--batch-ui` / `--app-ui` 的 `--events`）送得到：悬停、单击、双击、滚动区。以后可以写成脚本自动验，这一条就能从清单上拿掉。记号只说「送得到」，脚本还没写。点击只在照发版办法构建的程序上送得到（链接 macOS 15 的 SDK；细节见 `Sources/LabelGUI/SnapshotEvents.swift` 文件头，`LabelGUI --events-selftest` 每次实测）。
- 没有记号 = 只能真人点：拖放、捏合、拼图画布的 ⌘滚轮和右键（靠事件监听接的）、真的弹出框 / 菜单 / 文件框、动画的观感、真滚动条。

## 主题（v1.32.0）

- 状态栏右下角的半圆按钮：点开是六张小样；点一张立刻换，框不关；现在这套有描边和勾。批量、水印、拼图三页的状态栏都有。
- 「显示 › 主题」菜单里六项，带勾的是现在这套；和状态栏那个是同一个设置。
- 换主题时颜色是渐变过去的（约 0.2 秒），不闪、不跳布局、滚动位置不动。
- 深色之间来回换、深色换到「相纸」再换回来：系统控件（下拉、复选框、分段控件、滑杆）的字和底都跟着变，没有留在上一套颜色里的。
- 换到「相纸」：窗口标题栏、页签条变浅；sheet（这一版新增、导卡、按机身对时）和弹出框也是浅的。
- 退出重开，还是上次选的那套。
- 「相纸」下看大图、审片、标注校准的照片四周仍然是黑的；格子上的黑底角标照旧。
- 「纯黑」下格子和底分得开吗（照片暗部和底是同一个黑，这是这套的本意，觉得糊就用石墨）。
- 快捷键一览的独立窗口（帮助 › 快捷键一览）也跟着主题。

## 批量

- [ ] 〔假〕鼠标停在一张缩略图上 → 图下沿冒出「★ ● ✕」一小条，挪开就没了；点 ✕ 这张进废片区。
- [ ] 〔假〕缩略图滑杆拉到最小，停在一张竖片上 → 悬停条没伸到隔壁格子，三个按钮都点得到。
- [ ] 选中一张按 3，再按 1 → 照片挪位有 0.2 秒动画；连按几张，看这个动画是顺还是拖手（去不去等你定）。
- [ ] 按分组视图里按 ↓ 走过几场 → 每下落到下一行位置最近的那张，一场最后一行按 ↓ 进下一场第一行，网格跟着滚。
- [ ] 系统设置里把滚动条设成「始终显示」再看网格 → 每行右边贴着滚动条，没有被它盖住半张、也没有空出一截。
- [ ] 〔假〕点顶栏琥珀色的「挑连拍 N 场」→ 进连拍挑选；全挑完以后这个按钮没了。
- [ ] 点顶栏「导出 ▾」→ 弹出框出现在按钮正下方；窗口拉窄到两排时再点 → 只弹一个，不是两排各弹一个。
- [ ] 滚动网格，看上面的时间轴 → 「你在这」的白线跟着走，滚回顶上白线回到第一章。
- [ ] 〔假〕双击一张 → 打开检视器，照片是对的那张；Esc 回网格，焦点还在它上面。
- [ ] ⌘ 点三张、再按 2 → 三张都改判，状态栏说改了 3 张，选中清掉。

## 审片

- [ ] 点「审片」（或按 F），按 ← → 走十来张 → 换图跟手，底下胶片条的高亮跟着走。
- [ ] 审片里按 1 / 2 / 3 → 改判、自动到下一张；在一张连拍上按 C → 去挑这一场，⏎ 定完自动回到审片、停在按 C 的那张。
- [ ] 审片里按 Z 放大、P 看对焦高亮 → 放大的是这张、高亮标在清楚的地方；Esc 先退出放大，再按才退出审片。

## 连拍挑选

- [ ] 进一场 3 张以上的连拍，点其中一张 → 只留这张（绿框），其余标「废」（红底白字，深色照片上也看得清）。
- [ ] 按 ↑ ↓ 换组、⏎ 确认 → 进下一组；键盘高亮的细框和「留下」的绿框不像套了两个框。
- [ ] 〔假〕点右上角的角标 → 只改这一张，别的不动。

## 拼图

- [ ] 拖左栏、右栏的边 → 栏宽跟手；双击分隔条回默认；关 app 再开还是你拖的宽度。
- [ ] 按 ⌃⌘S、⌥⌘S → 左栏、右栏收起 / 摊开；收起后画布角上有按钮摊开。
- [ ] 在画布上捏合，或按住 ⌘ 滚滚轮 → 以指针那一点为中心放大 / 缩小；放大以后两指滚动是平移。
- [ ] 按 ⌘=、⌘-、⌘0、⌘1 → 放大、缩小、适应、实际像素；右下角百分比跟着变，放大后照片是重渲的清楚图不是拉大的糊图。
- [ ] 右键一个照片格 → 先选中它，再弹菜单（调整裁切、景别、换一张、移到第…个跨页、删除格子…）；点「删除格子」真的删了。
- [ ] 右键画布空白处、右键一条缝 → 各有各的菜单（换一批 / 参考线 / 缩放；横竖翻转）。
- [ ] 〔假〕鼠标停在备选条的一张上 → 画布底下浮出一张大的；挪开消失。
- [ ] 按住一个格子拖 → 有一张半透明小图跟着指针；松在另一格上两格对调。
- [ ] 〔假〕清空托盘后看空画布 → 中间有「带精选进来（N 张）」等按钮，点了照片进托盘并排好一版。
- [ ] 点一下托盘里的照片，再按 ← → → 换的是备选版式，不是托盘里的选中。
- [ ] 点托盘选中两张、按 ⌫ → 删的是托盘里这两张；再点一下画布上的格子按 ⌫ → 删的是格子（焦点没串）。
- [ ] 在托盘里快速单击几张 → 选中立刻亮，没有「等一下才选上」的迟滞（托盘是拖拽源）。
- [ ] 〔假〕「样式 › 风格」点「全部 N 个风格」→ 摊开全部预设；正在用的那个一直看得见。

## 相册

- [ ] 跨页条上拖一张卡片到别的位置 → 插入处有竖线，松手后顺序变了，⌘Z 一步撤回。
- [ ] 从托盘拖一张照片到跨页条的某张卡片上 → 照片当场进那个跨页并重排；同一张再拖一次 → 状态栏说它已经在第几个跨页上。
- [ ] 从画布上拖一个格子到另一张跨页卡片上 → 这张挪过去，两边都重排。
- [ ] 按 ⌘←、⌘→ → 换跨页；光标在输入框里时是挪光标。
- [ ] 按 G → 整本概览摊开；⌘ 点两张拖其中一张 → 两张一起挪；双击一张回到编辑那一页。
- [ ] 不选格子，按 Q / A、W / S → 左页、右页各自换切法，另一边不动。
- [ ] 右键照片格「移到第…个跨页」→ 跨页多时按 10 个一组，选一个后照片过去了。
- [ ] 选中一张，在「格式 › 换一张」里点一个候选 → 当场换；候选在别的跨页上时两格对调。
- [ ] 点跨页条最前面的「+ 封面」→ 进封面编辑，整张是封底｜书脊｜封面；从托盘拖一张照片到封面格上换掉它。

## 暗房

- [ ] 进暗房，鼠标慢慢扫过一排样张 → 大图跟着预览、不卡；挪开回到套着的那款。
- [ ] 按 ← → → 样张焦点左右走，按 ⏎ 套上；Esc 退出暗房。
- [ ] 抓住前后对比的竖线拖 → 好抓、跟手，不会一抓就变成拖照片。
- [ ] 按住看 1:1 放大镜 → 大小合适、位置跟着指针；放开消失。

## 水印

- [ ] 〔假〕点九宫格的右下、正中 → 预览里水印跟着跳，旁边的字写着现在的位置。
- [ ] 点「自定义」颜色块 → 弹系统取色器，选一个颜色预览跟着变。
- [ ] 在水印页导出一批 → 保存位置的面板弹出来；导完访达里选中结果。

## 导卡

- [ ] 插一张有照片的存储卡 → 弹「导入」框，写着张数和要去的文件夹（图片 / 当天日期）。
- [ ] 点导入 → 进度有剩余时间；导完自动开始分析，卡上的文件一个没少、没改。
- [ ] 「这一版新增」开着的时候插卡 → 新增那一页关掉以后导入框补弹出来。

## 退出与弹框

- [ ] 分析正跑着时按 ⌘Q → 弹确认（「停下并退出 / 继续」），选继续接着跑。
- [ ] app 开着时再双击一次 app 图标（或 `open -n`）→ 第二个实例弹「切换过去 / 退出」，点切换回到第一个窗口。
- [ ] 「帮助 › 导出诊断信息…」→ 保存面板弹出来，存下的压缩包里没有照片。
- [ ] 升级后第一次打开 → 弹「这一版新增」，「带我去」跳到对的页签；第二次打开不再弹。
- [ ] 按 ? → 快捷键一览弹出来，切到拼图 / 暗房页内容跟着换。

## AI 实时（MCP）

- [ ] 菜单打开「允许 AI 实时操作」，让 AI 换一个拼图模板 → 窗口里当场看见换了，标题栏副标题写着 AI 刚做了什么。
- [ ] AI 改完按 ⌘Z → 撤回的是 AI 那一步；AI 的 `app_undo` 只撤它自己的。
- [ ] 你正拖着滑杆时让 AI 改判 → AI 那边被告知「用户正在操作」，没有抢你手里的东西。
- [ ] AI 说「给我看这张」→ 网格滚到那张、焦点落上去。
- [ ] 关掉 app，再让 AI 调一个工具 → app 没有被拉起来，AI 得到「app 没开」。

## 标注校准

- [ ] 〔假〕在「和自动判决对比」里点一个「误杀」的照片名 → 跳到那张，那个名字描上琥珀边。
